# Mon Élevage Avicole — version vierge

Cette version démarre sans catégorie, volaille, vente, dépense ni stock préenregistré.
Les données saisies ensuite sont enregistrées localement sur cet appareil pour fonctionner hors ligne.
Cette version utilise un nouvel espace de stockage (mon_poulailler_vide_v2) afin de ne pas reprendre les anciennes données de l’ancienne version.

Pour publier : téléverser les fichiers et dossiers de cette archive à la racine du dépôt GitHub Pages.
